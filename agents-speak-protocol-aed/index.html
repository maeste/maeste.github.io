Alessio · 1:00–2:30. Three clicks: services, editors, agents — different boundaries, not a succession where one replaces the other. TCP/IP makes network communication interoperable; it does not define the operations of a service. In Web Services, WSDL described interface operations, messages and bindings, and SOAP structured the exchanged messages. REST-designed APIs: REST is an architectural style, not a WSDL-equivalent contract — HTTP methods, representations and API documentation still need concrete agreements between client and server. Do not introduce WS-Security here: the point is contract reuse, not WS-* stack complexity. LSP standardized editor–language-server interaction (methods, messages, capability negotiation): an editor reuses integrations across languages, within supported capabilities. Close by asking which agreement stops every pair from being rewritten; do not claim REST or LSP solve TCP/IP's problem.

Tools boundary

Every new tool multiplies the wiring

A shared interface changes the shape of integration

Alessio · 5:15–6:00. On the left, three applications and four services: twelve lines. On the click, three-plus-four connections through the contract. «Like JDBC: N applications, M databases. Either every pair gets its own integration, or we agree on an interface.» The formula counts integration surfaces in an ideal scenario, not development hours: adapters and tool semantics remain. Stefano · 13:30–15:30. MCP and A2A were the heart; now the same pattern at the remaining boundaries, all visible, one spoken beat per column. AG-UI gives a vocabulary for events and shared state between backend and frontend; A2UI describes declarative components rendered by the client from a supported catalog; MCP Apps lets a tool provide interactive UI inside a compatible host, isolated. Distinct contracts: no mandatory pipeline, not equivalents of WebSocket or HTML. AGENTS.md is essentially a file; a skill is a directory with SKILL.md and resources — technically simple, valuable when implementations agree on the same meaning; instructions are not authentication or permission. If you use OpenTelemetry, the trace does not appear by itself: instrument and propagate context at each boundary, and pin the GenAI convention version. «Opening a channel is not the agreement: WebSockets versus polling, all over again.» The user boundary matters too: make it explicit when the system waits for a human decision; a button does not confer a permission. Live-cut candidate: the operations column.
